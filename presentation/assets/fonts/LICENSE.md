# Bundled fonts

- **Inter** (weights 400, 500, 600, 700, 800) — SIL Open Font License 1.1.
  <https://github.com/rsms/inter>
- **DejaVu Sans subset** (weights 400 and 700, only the arrow and square-root glyphs
  missing from the Inter subset) — Bitstream Vera license / DejaVu changes are public
  domain. <https://dejavu-fonts.github.io/>

The woff2 files are embedded into `presentation/index.html` at build time and are only
used by the slide deck. The MIT license in the repository root covers the source code,
not these font files.
